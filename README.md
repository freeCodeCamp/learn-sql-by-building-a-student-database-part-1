# Learn SQL by Building a Student Database: Part 1

This is an interactive course that teaches you SQL fundamentals by building a student database from scratch. You'll learn how to create tables, define relationships, insert data, and write queries using PostgreSQL.

## Recommended Method

The easiest way to take this course is to use the **freeCodeCamp Learn Platform**:

👉 **[Start the Course on freeCodeCamp](https://www.freecodecamp.org/learn/relational-database/learn-sql-by-building-a-student-database-part-1/)**

This method provides an integrated learning environment with all the necessary tools and database setup handled automatically.

## Self-Hosting / Manual Setup

If you prefer to set up and run this course locally, follow these steps:

### 1. Find the Version Branch

Open the `coderoad.yaml` file in this repository and look for the `repo.branch` field:

```yaml
repo:
  branch: v3.0.0
```

Note the branch version (in this example: `v3.0.0`).

### 2. Clone the Version Branch

Clone this repository and check out the specific version branch:

```bash
git clone https://github.com/freeCodeCamp/learn-sql-by-building-a-student-database-part-1.git
cd learn-sql-by-building-a-student-database-part-1
git checkout v3.0.0
```

### 3. Locate Reset Files and Resources

All course materials are in the `.freeCodeCamp/reset_files/` directory:
- CSV data files for the course
- Database reset scripts
- Test files

### 4. Complete Setup Instructions

For detailed instructions on setting up your local environment, database configuration, and running the course, visit:

📚 **[freeCodeCamp Contributor Documentation](https://contribute.freecodecamp.org/how-to-work-on-coding-challenges/)**

This guide covers:
- Prerequisites and dependencies
- Database setup
- Running tests
- Submitting solutions
